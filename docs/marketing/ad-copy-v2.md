# ResumeTailor — Ad Copy v2 (loss-aversion + cited-data angle)

> Built on the **loss-aversion + value** angle from `campaign-plan-v2.md`:
> *you're losing jobs to a resume that doesn't match the posting → tailor it in
> ~30s and see your Match Score free.* All copy in **EN**, **pt-BR**, **ES**.
>
> **Compliance (hard rules):** No hiring/interview guarantees. The loss targets the
> **generic-resume status quo**, never "buy and you'll get this job." "Match Score"
> is a tool output on the user's own document. Only cite stats from
> `market-data-2026.md`, always with source + year. Never the "75% rejected by ATS"
> myth (or pt-BR "Gupy/ATS filtra 75%" / ES variants).
>
> **`[STAT: ...]` placeholders** must be filled from `market-data-2026.md`:
> - **S1** = ~98% of Fortune 500 use an ATS — Jobscan, 2025
> - **S2** = 62% of hiring managers: a generic/un-customized resume is more likely
>   rejected — Resume Now, 2025
> - **S3** = 53% higher callback for a tailored cover letter (16.4% vs 10.7%) —
>   ResumeGo, 2020
> - **S4** = 71% more callbacks for a comprehensive, effort-filled application —
>   ResumeGo, 2019
> - **S5** = ~7-second initial resume scan — Ladders, 2018
> - **S-BR** = Gupy is Brazil's dominant ATS; most hires came from its AI's top
>   recommendations — Gupy (color only, no guarantee)
>
> Pricing tokens: **$9** (EN) · **R$39** (pt-BR) · "pago único / desde $9" (ES).
> Whenever a stat appears on-creative or in caption, show "Source, YEAR" next to it.
